What is web development?

Web development is the work of creating and maintaining websites. It combines page structure, visual design, and interactive behavior to make useful experiences in a browser.

Core topics

HTML

HTML gives a page its structure. Use elements such as headings, paragraphs, lists, and links to describe the meaning of content.

CSS

CSS controls presentation, including colors, spacing, typography, and how content is arranged on different screen sizes.

JavaScript

JavaScript adds behavior, such as responding to user actions, updating page content, and loading data.

Build for everyone

Accessible websites work for people using keyboards, screen readers, and other assistive technology. Start with semantic HTML, clear labels, visible focus styles, and sufficient color contrast.

  • Use headings in a logical order.
  • Give form controls clear labels.
  • Write descriptive link text.
  • Make sure interactive controls work with a keyboard.
